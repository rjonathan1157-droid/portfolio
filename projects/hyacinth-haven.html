Project Overview

Hyacinth Haven is a flower-themed e-commerce application created as a database systems project. The goal was to combine relational database design with a functional web application.

My Contribution

I primarily worked on the shopping and cart functionality, including product browsing, cart management, removing items, and the checkout process.

Technologies

PHP MySQL HTML CSS Bootstrap SQL

Database

Designed around a relational MySQL database connecting customers, employees, products, categories, carts, orders, and order details.

FEATURES

What the system does.

01

Customer Accounts

Customers can create accounts, log in securely, browse products, manage their shopping cart, place orders, and review their order history.

02

Shopping Cart

Users can add products to their cart, view cart contents, remove products, update quantities, and continue through the checkout process.

03

Product Management

Products are stored dynamically in the database with information such as names, descriptions, prices, inventory quantities, and categories.

04

Order Processing

The application tracks customer orders and order details, allowing customers and authorized employees to access order-related information.

05

Inventory Management

Employees and managers can work with product inventory and update stock information through protected administrative areas.

06

Role-Based Access

Different user roles receive different permissions, including customers, employees, managers, and database administrators.

MY CONTRIBUTION

Building the shopping system.

Shop

Developed functionality for browsing and displaying products from the MySQL database, allowing customers to interact with the store dynamically.

Cart Management

Worked on the functionality that allows customers to view their cart, update cart contents, and remove products before checkout.

Checkout

Implemented the checkout workflow used to process the contents of the customer's shopping cart and create the corresponding order information.

PHP & MySQL Integration

Connected the shopping functionality to the relational database so that product and cart information could be retrieved and updated dynamically.

DATABASE DESIGN

A relational database.

Customers

Stores customer account information including names, email addresses, passwords, and addresses.

Products & Categories

Products are connected to categories and contain pricing, descriptions, and inventory information.

Orders

Orders connect customers to their purchases and store information such as order dates, totals, and status.

Cart System

Separate cart and cart-item tables allow customers to maintain products and quantities before placing an order.

SECURITY

Security was part of the design.

01

Password Hashing

User passwords were stored using password hashing rather than plain text credentials.

02

Prepared Statements

Prepared SQL statements and bound parameters were used in database operations to help prevent SQL injection.

03

Authentication

Login functionality verifies user credentials before providing access to protected areas of the application.

04

Role-Based Permissions

Administrative areas use session checks and user roles to restrict access to authorized functionality.

EXPERIENCE

What I learned.

Challenges & Lessons

Debugging syntax and logic problems across several PHP files while connecting the application to the database was one of the most difficult tasks.


The project also served as a reminder of the significance of SQL queries, database normalization, authentication, access control, and preserving functionality across various web application components.


Through the project, I was able to design features that mimic an actual e-commerce procedure and connect a relational database to a working web application.
