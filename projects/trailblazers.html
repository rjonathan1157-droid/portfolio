Project Overview

A web-based student portal called TrailBlazers was developed to give students a single place to access their current classes, assignments, announcements, and academic data.

Technologies

The project was developed using front-end web technologies and supporting frameworks.

HTML CSS Bootstrap Font Awesome Google Fonts

Key Features

Course Dashboard Calendar Announcements Class Pages Assignment Tracking

Course Dashboard

The main dashboard displays individual class cards with course information, upcoming assignments, and grades. Each course can be selected to view additional information.

Calendar

A dedicated calendar page was created to provide students with a simple view of their academic schedule.

Announcements

The announcements section allows students to view updates for individual courses and navigate directly to their class information.

Development Focus

I focused on creating a structured and easy-to-use interface while using HTML and CSS for layout and styling and Bootstrap components to help organize the application.

What I Learned

This project helped strengthen my understanding of web page structure, responsive layouts, navigation, reusable styling, and integrating multiple pages into a single web application.
